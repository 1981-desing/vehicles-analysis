# ANÁLISE DE VEÍCULOS
É um aplicativo que fornece informações para quem precisa encontrar / trocar ou comprar um veículo usado, contém um histograma que mostra informações do odometro do veículo e um gráfico de scatter que compara o odometro com relação ao preço para facilitar a vida das pessoas que procuram por um veículo.

## FUNCIONALIDADES
Um histograma que fornece informações do odometro de veículo.

Um gráfico para comparar o odometro com relação ao preço do veículo.
